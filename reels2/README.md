# Reels 5–8 · estilo chibi

`out/`: MP4 1080×1920 30 fps (H.264 + AAC, −14 LUFS) y portada PNG de cada reel.
Voz ElevenLabs v4 (Helena), subtítulos sincronizados con Scribe, música lo-fi generada (sin copyright) mezclada con ducking.

Regenerar: `python3 src/build.py` y `node src/render.js <reel>` (`--cover` para la portada, `--check` para validar el layout).
